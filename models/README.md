# Ball balancer v2 CAD assets

## Structure

- `fusion/ball_balancer.f3d`: complete Fusion design
- `fusion/urdf_rdy_ball_balancer.f3d`: Fusion design prepared for URDF export
- `stl/`: ready-to-print parts
- `urdf/`: URDF models, meshes and launch files
- `urdf/isaac/`: corrected Isaac Sim import package
- `usd/scene.usda`: ready-to-open Isaac Sim scene
- `usd/ball_balancer/`: USD model and payloads
- `servo/`: generated, reviewable servo-identification output
